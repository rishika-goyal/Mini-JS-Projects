# emailValidator
📧 Email Validator — HTML | CSS | JavaScript  A simple and fast Email Validator built using HTML, CSS, and JavaScript. It checks if the entered email is valid using both browser validation, and gives instant feedback to the user.

✨ Features
✔ Validates email format in real-time
✔ Uses HTML5 email validation 
✔ Instant success or error message
✔ Clean and modern UI
✔ Example test emails
✔ No backend required — fully frontend
