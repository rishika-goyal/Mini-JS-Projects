# passwordManager
This is a simple and secure Password Manager Website created using HTML, CSS, and JavaScript. It allows users to store, view, copy, and delete passwords — all inside the browser using localStorage.  


✨ Features
✔ Add New Passwords
✔ Store Website / Username / Password
✔ LocalStorage Support (data saved in your browser)
✔ Show / Hide Password
✔ Copy Password to Clipboard
✔ Delete Saved Passwords
✔ Clean and Responsive Design


🛠️ Technologies Used
HTML – for structure
CSS – for styling
JavaScript – for functionality
LocalStorage – to store data on browser


🚀 How to Use
Open the website in your browser.
Add website name, username, and password in the form.
Click Add to save the password.
Your saved passwords will appear in a list.
You can copy, view, or delete any saved password.


📌 Note
This password manager stores data in localStorage, which is suitable for personal use only.
